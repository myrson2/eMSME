# Agent Frontend Builder Skill

> **Full instructions are in [`eMSME_frontend_skill.md`](./eMSME_frontend_skill.md)** in this same folder.  
> Read that file before writing any mobile screen or component.

## Quick Reference

- **Platform:** React Native (Expo SDK) + NativeWind
- **Primary Colors:** Philippine Blue `#0038A8`, Gold `#FCD116`, Red `#CE1126`
- **Typography:** Use Expo Google Fonts (`@expo-google-fonts/inter`)
- **Component Location:** `mobile/src/components/`
- **Screen Location:** `mobile/src/screens/`
- **DO NOT** build app UI in `frontend/` — that is strictly a landing page.
